Como obter File ID de mídia
1. Abra o Telegram e mande a foto ou vídeo diretamente para o seu bot (no chat privado com ele)
2. O bot vai responder com o File ID automaticamente
3. Copie o File ID e cole nos campos de mídia das telas acima
Como hospedar gratuitamente
Railway.app (recomendado)
1. Crie conta em railway.app
2. New Project → Deploy from GitHub (suba a pasta do bot)
3. Adicione variável de ambiente: nenhuma necessária (token fica no data.json)
4. O bot fica online 24h grátis

Render.com (alternativa)
1. Crie conta em render.com
2. New Web Service → conecte o repositório
3. Start command: python bot.py
